## 目的

- タブ（Tab Pages）は作業領域（ワークスペース）の区切りとして扱い、頻繁に切り替える移動対象とはしない
- バッファは編集対象として頻繁に切り替える対象とし、ファイル名の視認性を重視する

## タブ表示（Tab Pages）

- lualine における「現在のタブ番号 / 総タブ数」の表示を維持する
- 表示形式は `n/N`（例: `1/3`）とする
- タブに個別名称を付けて表示する運用は原則として想定しない

## バッファ表示

- 画面上部のバッファラインに、開いているバッファをタブ風の UI で一覧表示する
- 表示対象は listed なバッファ全体とする（他のタブで開いているバッファも含む）
