## 目的

Neovim のバッファ、ウィンドウ、タブを別の概念として扱い、表示、キーバインド、終了操作の意味を一致させます。
プラグインが操作や表示を実装する場合も、Neovim が定義する概念を基準にします。

## 概念と関係

Neovim の各概念を次の意味で使用します。

| 概念       | 意味                                   |
| ---------- | -------------------------------------- |
| バッファ   | 編集対象となるメモリ上のテキスト       |
| ウィンドウ | 1 つのバッファを参照して表示する枠     |
| タブ       | 1 つ以上のウィンドウをまとめる配置単位 |

ウィンドウは必ず 1 つのタブに属し、1 つのバッファを参照します。
バッファはウィンドウやタブに所属せず、同じバッファを複数のウィンドウやタブから参照できます。
どのウィンドウからも参照されていないバッファも存在できます。

この文書とキーバインドでは、`b` をバッファ、`w` をウィンドウ、`t` をタブの目的語として使用します。
プラグイン固有の概念にこれらの略記を割り当てません。

## バッファの状態

バッファの状態は、ウィンドウからの参照と本文の読み込み状態によって決まります。

| 状態     | ウィンドウに表示 | 本文をメモリに保持 | `:ls` の表示 |
| -------- | ---------------- | ------------------ | ------------ |
| active   | あり             | あり               | `a`          |
| hidden   | なし             | あり               | `h`          |
| inactive | なし             | なし               | 空欄         |

inactive はバッファ自体が破棄された状態ではありません。
本文は unload されていますが、バッファ番号や一部の設定は残ります。

## ウィンドウとタブを閉じたときの動作

ウィンドウやタブを閉じる操作は、バッファを削除する操作ではありません。
閉じた後も別のウィンドウが同じバッファを表示していれば、そのバッファは active のままです。

どのウィンドウからも参照されなくなったバッファは、`'hidden'` とバッファ固有の `'bufhidden'` に従って状態が変わります。

| 条件                                              | バッファの状態           |
| ------------------------------------------------- | ------------------------ |
| `'hidden'` が有効                                 | hidden                   |
| `'hidden'` が無効で、バッファに未保存の変更がない | inactive                 |
| `'bufhidden'` に値がある                          | バッファ固有の指定を優先 |

`'hidden'` が無効で、他のウィンドウに表示されていないバッファに未保存の変更がある場合、通常の close は失敗します。
保存、強制実行、`'autowrite'` などの条件によって結果が変わるため、未保存の変更がある場合は単純に inactive には移行しません。

通常のファイルバッファでは `'hidden'` を有効にします。
ウィンドウやタブを閉じても未保存の変更と undo 情報を維持でき、表示領域と編集対象を独立して扱えるためです。
Neovim の既定値に依存せず、設定にも `hidden = true` を明記します。

一時的なバッファや特殊バッファの終了方法は、各プラグインが `'bufhidden'` で指定できます。
通常のファイルバッファに `unload`、`delete`、`wipe` を指定すると変更を警告なしで失う可能性があるため、全体設定では使用しません。

## 終了操作の用語

表示領域と編集対象の終了を区別します。

- close
  - ウィンドウまたはタブを閉じる
  - 参照先のバッファは削除しない
- delete
  - バッファを unload して buffer list から外す
  - ウィンドウ配置を維持するため、キーバインドでは `Snacks.bufdelete` を使用する
- quit
  - キーバインド上では終了する対象を選ぶ動詞として使用する
  - `qw` と `qt` は close、`qb` は delete を実行する

## 表示方針

画面上部の bufferline には、`bufferline.nvim` の `mode = "tabs"` を使用して Neovim のタブを表示します。
プラグイン名に bufferline と含まれていますが、表示対象はバッファではありません。

バッファは画面上部に常時並べず、buffer picker と前後移動で選択します。
タブはウィンドウ配置を切り替える対象として扱い、ファイルごとに作成する運用は前提としません。
lualine には、現在のタブ番号と総タブ数を `n/N` の形式で表示します。

## 操作方針

バッファ、ウィンドウ、タブの生成と終了は `<leader>` から始まる `動詞 + 目的語` のキーへ割り当てます。
生成には `n`、終了には `q` を使用します。
前後移動は `[` と `]`、ウィンドウ間の方向移動は `<C-h/j/k/l>` を使用します。
`<leader>nt` でタブを作成すると、そのタブに Alpha のダッシュボードを表示します。

具体的な割り当ては [Neovim キーバインド設計](./keybinds.md) で管理します。
