# todo.txt 運用ガイド

## 保存先

タスクは、環境変数 `DIR_TODO_NOTES` が示すディレクトリに保存します。
配備される mise の設定により、ホームディレクトリの環境変数から既定値 `$HOME/Documents/todotxt` が自動的に設定されます。
todotxt.nvim は初回読み込み時に保存先の存在を確認し、ディレクトリが存在しない場合はディレクトリ本体と空の `todo.txt`、`done.txt` を自動生成します。

## 書式

未完了のタスクは、`todo.txt` に 1 行ずつ記述します。

```text
(A) 2026-08-30 経費精算を提出する due:2026-09-01 @office +admin
```

次の要素は必要に応じて省略できます。

- `(A)`: 優先度
- `2026-08-30`: 作成日
- `due:2026-09-01`: 期限
- `@office`: コンテキスト
- `+admin`: プロジェクト

完了したタスクには、行頭に `x` と完了日が自動的に付与されます。

```text
x 2026-08-31 2026-08-30 経費精算を提出する @office +admin
```

## Neovim での操作

`<leader>` キーには Space キーを割り当てています。

| キー         | 動作                                       |
| ------------ | ------------------------------------------ |
| `<leader>tn` | 新しいタスクを追加する                     |
| `<leader>tt` | `todo.txt` のウィンドウを開閉する          |
| `<leader>td` | `done.txt` のウィンドウを開閉する          |
| `<leader>tg` | 優先度の補助表示（ghost text）を切り替える |
| `ra`         | カーソル位置のタスクに対する操作を表示する |

`<leader>tn` でタスク本文を入力すると、現在の日付が作成日として自動付与されます。
もちろん、`todo.txt` を直接エディタで開いて編集・保存することも可能です。

`ra` で表示される操作メニューから、完了状態や優先度の変更、ソート、完了タスクの `done.txt` へのアーカイブ移動などが実行できます。
編集モード中に `(`、`+`、`@` を入力すると、それぞれ優先度、プロジェクト、コンテキストの補完候補が表示されます。

## トラブルシューティング

TodoTxt のキーを入力した際にコマンドが見つからない旨のエラーが表示された場合は、ログインシェルを起動し直してから Neovim を再起動してください。

```sh
exec zsh -l
```

Neovim 側で認識されている保存先パスは、次のコマンドで確認できます。

```vim
:echo $DIR_TODO_NOTES
```

起動時のエラーログは `:messages` で確認できます。
