# todo.txt 運用ガイド

## 保存先

タスクは、`DIR_TODO_NOTES` が示すディレクトリに保存する。
配備される mise 設定では、ホームディレクトリの環境変数から既定値の `$HOME/Documents/todotxt` を組み立てる。
todotxt.nvim は初回読み込み時に保存先を確認し、存在しないディレクトリと `todo.txt`、`done.txt` を作成する。

## 書式

未完了のタスクは、`todo.txt` に 1 行ずつ記述する。

```text
(A) 2026-08-30 経費精算を提出する due:2026-09-01 @office +admin
```

次の要素は省略できる。

- `(A)`: 優先度
- `2026-08-30`: 作成日
- `due:2026-09-01`: 期限
- `@office`: コンテキスト
- `+admin`: プロジェクト

完了したタスクには、行頭に `x` と完了日が付く。

```text
x 2026-08-31 2026-08-30 経費精算を提出する @office +admin
```

## Neovim での操作

`<leader>` には Space キーを割り当てている。

| キー         | 動作                                       |
| ------------ | ------------------------------------------ |
| `<leader>tn` | 新しいタスクを追加する                     |
| `<leader>tt` | `todo.txt` のウィンドウを開閉する          |
| `<leader>td` | `done.txt` のウィンドウを開閉する          |
| `<leader>tg` | 優先度の補助表示（ghost text）を切り替える |
| `ra`         | カーソル位置のタスクに対する操作を表示する |

`<leader>tn` でタスク本文を入力すると、現在の日付が自動で付く。
`todo.txt` を直接編集して保存してもよい。

`ra` で表示する操作一覧から、完了状態や優先度の変更、並べ替え、完了したタスクの `done.txt` への移動ができる。
編集中に `(`、`+`、`@` を入力すると、それぞれ優先度、プロジェクト、コンテキストの補完候補が表示される。

## トラブルシューティング

TodoTxt のキーを押したときにコマンドを利用できないと表示された場合は、次のコマンドでログインシェルを起動し直してから Neovim を再起動する。

```sh
exec zsh -l
```

Neovim から見える保存先は、次のコマンドで確認する。

```vim
:echo $DIR_TODO_NOTES
```

起動時のエラーは `:messages` で確認できる。
