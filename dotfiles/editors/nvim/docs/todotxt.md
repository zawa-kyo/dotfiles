## 保存先

タスクは、環境変数 `DIR_TODO_NOTES` が示すディレクトリに保存します。
リポジトリ内の mise 設定により、既定では環境変数 `DIR_TODO_NOTES` に `$HOME/Documents/todotxt` が設定されます。
todotxt.nvim は初回読み込み時にこの保存先ディレクトリの存在を確認し、存在しない場合はディレクトリ本体および空の `todo.txt`、`done.txt` を自動生成します。

## 書式

未完了のタスクは、`todo.txt` に 1 行ずつ記述します。

```text
(A) 2026-08-30 経費精算を提出する due:2026-09-01 @office +admin
```

次の要素は必要に応じて省略できます。

- `(A)`: 優先度
- `2026-08-30`: 作成日
- `due:2026-09-01`: 期限
- `@office`: コンテキスト
- `+admin`: プロジェクト

完了したタスクには、行頭に `x` と完了日が自動的に付与されます。

```text
x 2026-08-31 2026-08-30 経費精算を提出する @office +admin
```

## Neovim での操作

`<leader>` キーには Space キーを割り当てています。

| キー          | 動作                                       |
| ------------- | ------------------------------------------ |
| `<leader>nT`  | 新しいタスクを追加する                     |
| `<leader>tTm` | `todo.txt` のウィンドウを開閉する          |
| `<leader>tTd` | `done.txt` のウィンドウを開閉する          |
| `<leader>tTg` | 優先度の補助表示 (ghost text) を切り替える |
| `ra`          | カーソル位置のタスクに対する操作を表示する |

`<leader>tT` から始まるキーは、todo.txt 関連の表示切り替え (toggle) を担当します。
末尾のキーは対象を表し、`m` はメインの `todo.txt`、`d` は `done.txt`、`g` はタスク入力時の補助表示 (ghost text) に対応しています。
補助表示を有効にすると、優先度、プロジェクト、コンテキストの入力位置に候補がプレビュー表示されます。

タスクの新規追加には `<leader>nT` (new Todo) を使用します。プロンプトからタスク本文を入力すると、作成日 (今日の日付) が自動付与されて `todo.txt` に追記されます。
もちろん、`todo.txt` を通常のエディタバッファとして直接開いて編集・保存することも可能です。

タスク行で `ra` (reveal action) を入力すると操作メニューが開き、完了状態や優先度の変更、ソート、完了タスクの `done.txt` へのアーカイブ移動などが実行できます。
編集モード (挿入モード) 中に `(`、`+`、`@` を入力すると、それぞれ優先度、プロジェクト、コンテキストの補完候補が表示されます。

## トラブルシューティング

TodoTxt のキーを入力した際にコマンドが見つからない旨のエラーが表示された場合は、ログインシェルを起動し直してから Neovim を再起動してください。

```sh
exec zsh -l
```

Neovim 側で認識されている保存先パスは、次のコマンドで確認できます。

```vim
:echo $DIR_TODO_NOTES
```

起動時のエラーログは `:messages` で確認できます。
