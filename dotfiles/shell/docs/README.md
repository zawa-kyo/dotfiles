# シェル環境（Zsh）設計・運用ガイド

## 目的

Zsh を中心としたターミナル環境の起動順序、プラグイン管理、プロンプト表示、高速化の工夫についてまとめます。

## 主要構成

| ディレクトリ / ファイル    | 役割                             |
| -------------------------- | -------------------------------- |
| `dotfiles/shell/terminal/` | Zsh 設定ファイル群               |
| `dotfiles/shell/sheldon/`  | Sheldon の設定（`plugins.toml`） |
| `dotfiles/shell/starship/` | Starship の設定およびテーマ定義  |

## 起動順序とライフサイクル

Zsh の設定ファイルは次の順序で読み込まれます。

1. `.zshenv`: すべてのシェルセッションで読み込み。`$ZDOTDIR` や `XDG_*`、各種基本パス（`DIR_*`）などの環境変数を定義
2. `.zprofile`: ログインシェル時に読み込み。PATH の基本構成や言語環境などを設定
3. `.zshrc`: 対話型シェル時に読み込み。Sheldon によるプラグイン読み込み、Starship プロンプト初期化、mise の有効化、補完、エイリアス設定などを実施
4. `.zlogin`: ログイン完了時に読み込み。後処理やログイン時メッセージを表示

## パフォーマンスと最適化

- **Sheldon による並列キャッシュ**: プラグインの読み込みは Sheldon を介して最適化され、対話シェルの起動遅延を最小限に抑えます。
- **mise hook の最適化**: プロンプト表示ごとのオーバーヘッドを削減するため、mise が既定で登録する `precmd` フックを解除し、ディレクトリ移動時（`chpwd`）にのみ環境を更新する構成にしています。
- **非同期プロンプト**: Starship による Git ステータス表示などを非同期・高効率に処理し、軽快な入力応答性を維持します。
